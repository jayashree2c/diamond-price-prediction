Diamond Price Prediction

Overview:
This project predicts diamond prices using various machine learning regression algorithms. The objective is to analyse the relationship between diamond features and price, and build a model that accurately estimates the market value.

Dataset Features:
- Carat
- Cut
- Colour
- Clarity
- Depth
- Table
- Dimensions (x, y, z)

Workflow:
1. Data cleaning and preprocessing
2. Handling categorical variables using encoding techniques
3. Feature scaling and transformation
4. Train-test split
5. Model training and comparison
6. Performance evaluation

Models Implemented:
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- K-Nearest Neighbours Regressor
- XGBoost Regressor

Evaluation Metrics:
- R² Score
- Mean Squared Error (MSE)
- Cross-validation Score

Best Performing Model:
Best Performing Model:
Random Forest Regressor showed strong performance compared to baseline linear models in terms of R² score.

Technologies Used:
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost
